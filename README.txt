WORLD AT WAR 1939 — v1.0 Europe 60 Territory Test

사용 방법 (아이폰 / GitHub Pages)
1. ZIP을 다운로드한 다음 iPhone 파일 앱에서 압축 해제합니다.
2. 압축을 푼 폴더의 index.html을 GitHub 저장소 h87chwtrf2-art/waw-1939 의 맨 위(main 브랜치 루트)에 업로드 또는 기존 index.html 교체합니다.
3. Pages 배포가 반영되면 https://h87chwtrf2-art.github.io/waw-1939/ 에서 플레이합니다.
4. 이전 v0.9 게임 저장값과 별도로 저장됩니다.

포함한 기능
- 1939년 유럽을 단순화한 60개 영토, 25개 국가, 개략적인 유럽 해안선 및 지역 연결
- 유럽 내 도시/지역 이름, 수도 표기, 국가색, 지역별 병력, 지형 25% 단위 비율
- 병력 모집 / 공장 설립 없음, 국가별 고정 시작 병력
- 매달 최대 병력 한도의 5% 자동 회복 (국가별 회복률 차등은 아직 결정하지 않아 통일)
- 영토 1개 추가 점령 시 최대 병력 +20,000명 / 영토 상실 시 한도 감소
- 한 달 1번 이동 또는 공격, 병력 25/50/75% 선택, 지형 혼합 방어 보너스
- 자동 AI 전쟁/병력 회복, 자유 대체역사, 국가 간 동맹/선전포고/평화 요청
- 강대국에 보호 요청, 보호국 병력 자체 운영, 독립 선언 및 종주국 반발
- 20개 지역 확보 시 목표 달성 / 60개 지역 완전 정복 / 전멸 시 패배
- Safari localStorage 자동 저장

참고 사항
- 역사적 국가와 지명은 참고했지만, 국경선, 해안선, 지형 비율, 군대 수치와 AI 정책은 테스트용 단순화한 가상 데이터입니다.
- 실제 1939년 당시 정확한 국경이나 역사적 전쟁 전개를 재현하지 않습니다.
- 미국과 일본은 유럽 60지역 지도에 포함하지 않았습니다.
- 웹 브라우저의 터치·확대/축소 기능은 iPhone Safari 실기기에서 추가 테스트가 필요합니다.
- HTML 하나만으로 작동하며 추가 인터넷 API / 외부 라이브러리가 필요하지 않습니다.
