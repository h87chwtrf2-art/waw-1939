WORLD AT WAR 1939 — 사단장 시뮬레이터 v2.0 (중간점검)

아이폰 세로 화면용, 1939년 유럽 60개 지역을 배경으로 한 1인용 웹게임입니다.

설치/실행:
1) ZIP을 압축 해제합니다.
2) index.html을 GitHub Pages 저장소의 main 브랜치 최상위(root)에 업로드하여 기존 index.html을 교체합니다.
3) GitHub Pages 주소를 Safari에서 열어 주세요.
4) 기존 페이지가 표시되면 Safari 새로고침을 해 주세요.

핵심 조작:
- 국가 선택 → 사단장 부임 → 명령 탭에서 3개 보병연대의 방어/공격/이동을 지정
- 전차/전투기/군함은 명령 탭에서 각각 이동/지원 명령 지정
- 1주 진행하기를 누르면 명령 이행 판정 → 필요 시 선택지 대화 → 동시 전투 및 회복 → 상부 보고
- 명령 거부 시 설득/경고/의견 수용/교체 요청 중 선택
- 경력 탭에서 전투 기록과 12주마다의 진급 심사 확인
- 자동 저장은 이 기기의 브라우저에 보관됩니다.

현재 버전의 단순화 사항:
- 유럽 지역 경계선은 개략적인 게임용 구역이며 1939년 국경의 정밀 재현이 아닙니다.
- 장비 수량, 장교 이름, 군대 배치는 역사적 기록을 그대로 재현하지 않은 가상 수치입니다.
- 항공기·군함 작전과 타국 AI의 행동은 시제품용 간이 규칙입니다.
- 전투 및 상부 AI는 규칙 기반이며 생성형 AI 대화가 없습니다.
- 국가의 최대 병력은 점령 지역 1개마다 +20,000명 증가합니다. 플레이어 사단에 배정되는 몫은 일부로 제한되어 있습니다.
- 기존 게임 기록과 분리된 저장 키를 사용하며, 새 버전의 기록은 이전 게임과 호환되지 않습니다.
- 모바일 Safari 실기기 테스트는 아직 하지 못했습니다.
